# 发布说明

## 生成交付物

```sh
npm ci
npm test
npm run demo:export
npx playwright install chromium
npm run demo:verify
npm run source:export
```

`demo-release/AI-Switcher-Demo.html` 是可双击打开的离线演示。

`source-release/AI-Switcher-时间戳/` 是可上传的源码目录。它仅包含明确列出的前端源码、品牌资源、构建脚本、文档和自动检查配置，附有 `源码清单.json`。每次生成新目录，不覆盖先前的交付物。

公开源码不含原生后端、原项目 Git 历史、安装脚本、开发者个人目录和旧版账号验收记录。不要直接上传开发工作副本及其 Git 历史；请以导出的干净目录初始化新仓库。

## 发布到 GitHub

仓库地址由维护者确定。在干净源码目录初始化仓库并创建首次 commit，再关联目标远程仓库。首个版本建议提供源码及离线 HTML；截图已经放在 `docs/images/`。

GitHub Actions 的“构建和检查”覆盖 Windows、macOS、Linux。“打包离线演示”可手动触发，生成供下载的构建产物；它不会自动创建公开 Release。Release 与公开仓库需由维护者选择版本和目标后发布。

如使用 GitHub Pages，将 `dist/` 作为静态站点产物。构建使用相对资源路径，支持仓库子目录；本地核验可运行 `npm run demo:serve`。
