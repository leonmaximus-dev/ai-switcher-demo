# 开发路线

## 已完成的演示范围

16 个应用入口，独立示例账号，确认及取消切换，添加和移除账号，账号搜索，分类和应用显示管理，主题和隐私模式，缓存校验、局部恢复与重置，离线 HTML 导出。

同时提供纯前端源码导出、跨平台自动检查、贡献指引和浏览器核验。所有额度、套餐和切换动作均为模拟。

## 后续真实应用接入

先选一个应用完成完整闭环，再扩展到其他应用。建议优先使用厂商公开的 OAuth2 或官方账号管理接口；是否提供相应接口需要单独验证。本演示目录中的品牌不代表存在可用的账号切换接口。

推荐的适配层应分别提供账号列表、当前账号、认证状态、额度读取与切换动作。数据应标记 `demo`、`connected`、`pending`、`error` 和 `stale` 等来源状态；未接入、读取失败或缓存过期时不能生成假额度。

实际切换需要单独处理进程状态、备份、失败回滚和凭据加密。验证应包含真实 A/B 账号双向切换、取消、失败恢复、身份一致性和权限边界。浏览器模拟测试不能替代这一步。

## 产品扩展方向

- 按应用调整额度窗口，不强制所有厂商使用相同的“5 小时”。
- 将自定义账号标签、应用排序和批量配置作为后续独立功能。
- 接入真实数据后，增加缓存更新时间及过期提示。
- 如提供桌面客户端，单独建立原生实现、安装流程与平台验收。
