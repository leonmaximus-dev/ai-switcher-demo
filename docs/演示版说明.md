# 演示版说明

本版用于录屏、产品展示和开源案例。16 个应用入口提供统一的账号卡片和交互反馈，账号、套餐、额度、重置时间和可用状态均为示例数据。真实应用适配范围见 [开发路线](开发路线.md)。

## 操作范围

- 选择应用，筛选国内或海外，隐藏和重新显示应用。
- 在确认弹窗中切换示例账号，查看分步反馈，或取消切换。
- 添加和移除展示账号，按昵称或邮箱搜索，每个应用最多 100 个账号。
- 使用深浅主题和隐藏邮箱的隐私模式。
- 刷新示例状态，重置数据，刷新页面保留状态。

账号只用于展示，请使用虚构昵称和邮箱。隐私模式不加密浏览器保存数据。

## 实现范围

纯浏览器前端，不调用原生认证、进程退出、凭据恢复和真实应用切换。状态使用 `ai-switcher-demo:v1` 保存项，损坏的数据按应用恢复默认值，未知字段被丢弃。浏览器不允许持久保存时，本次页面仍可交互。

图标随源码保存；离线 HTML 完全内嵌图标、样式和交互，无需运行服务器。源码下载后的导出方式见 [README](../README.md)。

## 录屏

建议顺序：展示完整应用栏 → 打开 Qoder 或 ZCode → 切到工作账号 → 打开 Cursor 展示独立状态 → 开启隐私模式和深色主题。

保留“交互演示”和“示例”标记，介绍为可体验的产品原型。不能将动画反馈描述为真实应用切换结果。

## 检查与资源

运行 `npm test` 和 `npm run demo:verify` 获取当前源码的检查结果；报告与截图放在不进入 Git 的 `docs/local/`。公开文档截图放在 `docs/images/`，只含示例数据。

多数品牌图形来自 Lobe Icons，Factory、Typeless、ZCode 图标来自厂商网站，来源与许可说明保留于 `docs/third-party/`。AI Switcher 的双向箭头图标为项目自有图形。
